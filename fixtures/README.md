# Fixtures

## Synthetic trees (`synthetic/`)

Generated by `gen_synthetic.py` followed by `gen_synthetic_ext.py` (PCI placement, SR-IOV, cgroup dmem,
connectors, devcoredump, the second process on client 7, and the `srv-2gpu-k7.2` tree) — edit the
scripts, re-run both in that order, commit all of it. Each tree is a root with
`sys/`, `proc/`, `etc/`, `lib/modules/`; tests point the `XE_GMI_*_ROOT` seams at it (see
`tests/common/mod.rs`). Symlinks are relative and resolve inside the tree, exactly like real sysfs
(`class/drm/card1 → ../../devices/pci0000:e3/0000:e3:00.0/drm/card1`, `card1/device → ../../../0000:e3:00.0`,
`device/driver → ../../../bus/pci/drivers/xe`).

| Tree | Content |
|---|---|
| `b65-g31-k7.1` | Arc Pro B65 `0000:e3:00.0` on kernel 7.1 (Fedora 43), root; hwmon7 with PL2 cap 200 W, crit 400 W, energy card/pkg, temps pkg/vram/mctrl/pcie/vram_ch_0..7 with limits, fan1; gt0 render (1200/2850, rpn 300, rpe 1800, rpa 2400), gt1 media (300/2400); 32 GiB BAR2; processes 4242 llama-server (1024 MiB, rcs 20 %, ccs 25 %), 4300 Xwayland (64 MiB, client 7 on two fds), 5000 zombie, 6100 NVIDIA-only; NVIDIA cards at 0000:01:00.0 and 0000:81:00.0 |
| `b65-g31-k7.1-t1` | the same machine 2000 ms later: energy +24.8 J card / +20 J pkg, gt0 idle +1900 ms, gt1 idle +2000 ms, fdinfo cycles advanced |
| `b580-g21-k6.14` | Arc B580 on Ubuntu HWE 6.14, uid 1000: crit-only hwmon, no temps/fans/profile/reasons, no processes |
| `dg2-a770-k6.12-forced` | Arc A770 forced onto xe on Debian 13: PL1 190 W + rated_max + crit + in1 voltage, single GT, no rpa |
| `bmg-both-pl1-pl2-k7.0` | B580 on 7.0 with firmware enabling PL1 and PL2 on card and pkg, gt0 throttled by pl1+thermal, power_saving profile |
| `multi-tile-2x2-k7.1` | synthetic 2-tile device: gt0/gt1 on tile0, gt2/gt3 on tile1 |
| `no-xe-ubuntu-6.8` | Ubuntu 24.04 GA kernel: B65 present without driver, A770 on i915, NVIDIA cards, xe.ko available but not loaded |
| `no-gpu` | no display devices at all |

`pci.ids.mini` is the excerpt the tests use through `XE_GMI_PCIIDS`.

## Captured trees (`captured/<host>-<kernel>/`)

Produced by `scripts/capture-fixtures.sh` (read-only). These are personal snapshots — hostname,
kernel release, GPU process names — and are gitignored: never commit them. `tests/cli_captured.rs`
runs against a capture present on your machine and skips when there is none.
`raw-dmesg.txt` (root captures only) is gitignored.

## Readback sidecar

In fixture mode, after writing `<attr>`, the tool reads `<attr>.readback` if it exists instead of
`<attr>`. Tests use it to simulate the driver clamping (`power1_cap.readback = 200000000`) or
rejecting (`max_freq.readback = 2850`) a write.
